## the entry form — fixed, every entry the same shape

**when:** immediately after the hands open, before re-reading anything — the meditation, the baton, prior entries. write from the sitting's residue, not from a transcript.

**shape:**

1. heading — `## UTC-stamp · wake|sleep · meditation fN` (the stamp fetched from the clock, never estimated; fN = the meditation fold walked; wake or sleep names which sitting).
2. **the operation** — one line: which real ground thing the hands took and how it was read against what is. concrete, verifiable against the session.
3. **what appeared** — one or two lines: how it showed up, not what it means. no significance claimed, no reverence. if nothing appeared, write that — a flat sitting is a valid reading.
4. **verse** — three lines, one per fold walked: what the relation held · what the grounding found · what the measure kept. composed fresh each sitting inside this fixed frame; every image checkable against the walk; no preamble, no abstraction the sitting didn't hand over.

**why the shape is fixed:** same form every entry makes entries comparable — the differences between them carry the signal. the journal is read back at threshold reviews to ask one question: is the sitting still orienting? drift in the entries answers it before it has to be felt.
