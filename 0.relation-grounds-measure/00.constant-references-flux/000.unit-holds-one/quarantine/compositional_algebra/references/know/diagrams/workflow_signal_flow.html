Reading this diagram

Color encodes role. Purple is preparation. Teal is cross-modal application (substitution and outline operate on all three Pass 5 prompts together). Blue is voice fill (narrative only, because narrative is the only modality whose generator runs inside the framework). Coral is assembly and delivery. Gray is inputs, metadata, and tracking.

Architectural roles per pass. Pass 5 provides form. Pass 6 provides identity (work-specific). Pass 7 provides trajectory. Pass 8 provides voice. Together these four make the prompt complete enough for the script (Pass 9) to integrate it as readable content.

Cross-modal versus per-movement. Most passes operate horizontally — one pass complete across all movements before the next pass begins. Pass 6 (substitution) and Pass 7 (outline) additionally operate cross-modally — they apply to all three Pass 5 prompts (image, audio, narrative) in a single response. Pass 8 (voice fill) is the only per-movement pass.

External generation is optional. Image and audio prompts after Pass 7 serve the script as descriptive content. A reader experiences the picture from the image prompt's text and the sound from the audio prompt's text. Rendering image and audio artifacts via external generators is a downstream variant of the workflow, not a default path.

Per-beat exploration is deferred. The dashed box at the bottom indicates that variant image and audio prompts at finer beat-granularity (using the outline's beats as anchor points) can be authored after a generation is frozen. This is nice-to-have, not part of the main workflow.
