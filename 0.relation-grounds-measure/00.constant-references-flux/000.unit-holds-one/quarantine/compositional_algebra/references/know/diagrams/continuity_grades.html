Continuity grades at the movement join

How the felt-quality function f_n crosses the boundary between two movements. C⁰ allows direction change. C¹ matches direction but allows curvature change. C² matches direction and curvature.

Framework version 20260527-150000. See framework/transition_reference.md in each work and the framework's S2 / S3 formalization notes in framework/parameter_space_reference.md.

Reading this diagram

The math under the felt. Each movement carries a felt-quality function f_n that runs from local time 0 (start of movement) to 1 (end of movement) and takes values in ℝ (the felt intensity scalar). At each movement join, the work commits to a continuity grade — how smoothly the function passes from movement N to movement N+1. This is qualitative at the framework's current Stage S2 (named in transition references as C⁰, C¹, C² with verbal characterization). At Stage S3 (a future formalization milestone) it becomes mathematically verifiable: derivative-matching at the join.

C⁰ — felt-shift. Function values match across the join, so the felt-quality intensity at the close of movement N equals the felt-quality intensity at the open of movement N+1. But the tangent direction can break — what was rising can become falling. The V-corner in the diagram visualizes this: same height at the join, sharp directional change. Use C⁰ when the work redirects without changing intensity — same emotional weight, new vector.

C¹ — shift-felt redirect. Function and first derivative both match. The intensity matches and the direction matches. But the curvature can change — the rate at which the function is curving toward or away from the tangent line can differ on each side. The diagram shows this as two curves meeting with a shared tangent at the join but with visibly different curvature on each side. Use C¹ when the work shifts register beneath continuous forward motion — the path keeps going in the same direction, but something about how it's bending has changed.

C² — unfold-felt continuity. Function, first derivative, and second derivative all match. No felt boundary at the join: one movement unfolds into the next without any audible or visible discontinuity in the curve. Use C² when a gesture begun in one movement completes in the next, when the second movement is the natural unfolding of the first rather than a new beginning.

Higher grades (C³+). Mathematically valid but the framework currently caps at C² because Shape (the sub-field that characterizes function behavior at start, interior, end) has three named characterizations. Higher-order matching (third derivative and beyond) would need additional Shape sub-fields to verify honestly. Open extension point in framework/transition_reference.md.

What makes the diagram math, not metaphor. The curves in this diagram are real functions. The C⁰ V-corner is a real directional discontinuity. The C¹ panel shows tangent-matching with curvature-mismatch. The C² panel shows a single smooth function. The "felt-like" annotations describe what each grade produces for a reader / listener, but the underlying commitment is mathematical. This is the framework's core claim materializing as a picture: math drives the felt; the felt is structured by math.
