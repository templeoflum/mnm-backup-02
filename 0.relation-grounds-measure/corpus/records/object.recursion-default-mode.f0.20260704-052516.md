**statement (plain)** — when people mentally represent a recursive rule (a structure that contains itself) versus a merely repeated one, different brain networks light up. Recursion engages the Default Mode Network — the internally-oriented system active at rest — while plain iteration engages the outward-facing control network. The suggestion: recursion sits close to the mind's resting default, not an effortful add-on.

**basis** — Fischmeister et al. (2017, *Cortex*): fMRI, 35 participants, visual recursion vs embedded iteration with identical final images — a double dissociation (recursion→DMN, iteration→fronto-parietal control). `empirical`; the finding is visual-domain, with supramodal generality (to language, music) offered as a hypothesis, not shown. Prior work: visual recursion is independent of verbal resources (Martins et al. 2015). Kin of [[object.recursion-in-language]]. [[source.fischmeister-2017]] **[confirmed]**
