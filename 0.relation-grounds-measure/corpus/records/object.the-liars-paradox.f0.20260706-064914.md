**statement (plain)** — Consider 'This sentence is false.' If it is true, then what it asserts holds, so it is false. If it is false, then what it asserts fails, so it is true. It oscillates, settling on neither truth value.

**statement (framework)** — the oldest and most consequential **semantic paradox**; Tarski showed a consistent formal language cannot contain its own truth predicate (truth must be defined in a metalanguage), and it drives contemporary theories of truth (Kripke's fixed points, paraconsistent/dialetheist responses). Established; the right theory of truth stays **open**.
