**statement (plain)** — If advanced civilizations can run many high-fidelity ancestor simulations, simulated minds would vastly outnumber original ones — so a random mind is probably simulated. Bostrom's trilemma: either (1) civilizations almost always go extinct first, or (2) almost none run such simulations, or (3) we are almost certainly living in one.

**statement (framework)** — the argument's force is the **trilemma structure**, not any single horn: accepting the premises forces one of three extraordinary conclusions (near-universal doom, convergent disinterest, or our own simulated nature). A self-locating/anthropic probability argument with a metaphysical payload. Established; which horn holds stays **open**.

**basis** — Bostrom's "Are You Living in a Computer Simulation?" (2003) [[source.bostrom-2003]]. **[confirmed as attribution]**
