**statement (plain)** — The tau effect is a spatiotemporal illusion in which the perceived spatial distance between sequential events is systematically influenced by the temporal interval separating them. Specifically, when two events are separated by a longer temporal interval, the spatial distance between them is perceived as greater than when the same objective spatial separation occurs with a shorter temporal interval. This phenomenon represents the temporal-to-spatial counterpart of the kappa effect, which describes the influence of spatial separation on perceived temporal duration.
