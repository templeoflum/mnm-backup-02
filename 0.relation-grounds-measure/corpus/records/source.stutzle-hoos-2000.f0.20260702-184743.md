Thomas Stützle and Holger H. Hoos, "MAX–MIN Ant System," *Future Generation Computer Systems* 16, no. 8 (2000): 889–914.

Contains — **MAX–MIN Ant System (MMAS)**, a widely-used Ant Colony Optimization [[object.ant-colony-optimization]] variant that (i) allows only the best ant to deposit pheromone and (ii) bounds pheromone values to an interval [τ_min, τ_max], preventing the search from stagnating on an early-found path — a principled handle on the exploration/convergence trade-off central to ACO.
