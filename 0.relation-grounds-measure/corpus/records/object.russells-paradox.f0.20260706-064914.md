**statement (plain)** — Let R be the set of all sets that are not members of themselves. Is R a member of itself? If it is, then by its definition it isn't; if it isn't, then by its definition it is. Either way, contradiction.

**statement (framework)** — a **proven** inconsistency in naive set theory (any property defines a set), triggering the foundational crisis and the move to axiomatic (ZFC) set theory with restricted comprehension. Kin to Cantor's and Burali-Forti's paradoxes. Proven.
