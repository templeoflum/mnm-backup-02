**statement (plain)** — Thiéry's Figure, described by Belgian psychologist Armand Thiéry in 1896, is an ambiguous line drawing that alternates between two distinct three-dimensional interpretations of stacked blocks or books viewed from different orientations. The figure typically depicts a configuration that can be seen either as a set of volumes stacked horizontally with their spines facing the viewer, or as the same volumes arranged vertically when viewed from a different angle, with the depth relationships reversing between interpretations. This bistable depth illusion demonstrates how identical two-dimensional contours can support multiple three-dimensional structural interpretations in the absence of definitive depth cues.

**statement (framework)** — category: ambiguous bistable multistable; perceptual mechanism(s): bistable-competition, depth-cue-conflict, top-down-expectation, bayesian-inference.
