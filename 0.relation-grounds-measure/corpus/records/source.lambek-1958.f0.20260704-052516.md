Role — the Lambek calculus: syntactic categories as types, constituents combining as functions and arguments via a small residuated-logic rule set applied recursively at every level; realizes Montague's compositionality "in an uncompromising way," with the Curry–Howard proofs-as-programs link between syntactic proofs and lambda-calculus meaning terms.
