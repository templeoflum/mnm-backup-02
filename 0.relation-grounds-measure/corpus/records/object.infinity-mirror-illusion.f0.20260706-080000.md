**statement (plain)** — The Infinity Mirror Illusion is a visual phenomenon created by positioning two parallel mirrors facing each other, resulting in the perception of an infinitely extending tunnel of reflections. When an object or light source is placed between the mirrors, viewers observe a seemingly endless corridor of progressively smaller, fainter duplicates receding into depth. This illusion exploits the visual system's interpretation of size gradients and luminance decay as depth cues, triggering perceptual mechanisms normally used to estimate distance in natural environments.
