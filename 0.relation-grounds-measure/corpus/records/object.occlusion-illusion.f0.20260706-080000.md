**statement (plain)** — The Occlusion Illusion describes a systematic bias in size perception whereby a partially occluded object appears larger than an identical fully visible object, despite both subtending the same retinal area in their visible portions. This phenomenon reflects the visual system's automatic tendency to complete surfaces behind occluders and to account for hidden portions when estimating object size. When an object is partially hidden by an occluding surface, perceptual mechanisms engage in amodal completion, mentally reconstructing the invisible portions based on visible contours and statistical regularities of natural scenes.
