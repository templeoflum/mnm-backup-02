**statement (plain)** — The Pulfrich Effect is a stereoscopic depth illusion discovered by German physicist Carl Pulfrich in 1922, in which an object moving laterally across the visual field appears to follow an elliptical path in depth when one eye receives reduced luminance input, typically through a neutral density filter. The illusion arises from the differential processing latency between the two eyes: dimmer images require longer neural processing time than brighter images. When a moving object is viewed with asymmetric luminance between the eyes, the temporal delay in the dimmed eye's signal causes the visual system to register the object's position at slightly different spatial locations for each eye, creating a spurious binocular disparity signal.
