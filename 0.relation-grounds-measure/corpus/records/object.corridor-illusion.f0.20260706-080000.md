**statement (plain)** — The Corridor Illusion is a depth-based size illusion in which identical objects positioned at different locations along a depicted corridor with linear perspective cues appear to differ substantially in size. Typically, an object placed at the apparent far end of the corridor, where perspective convergence suggests greater distance, appears larger than an identical object at the near end, despite both having the same retinal size. This compelling effect demonstrates the automatic operation of size constancy scaling mechanisms that normally compensate for the reduction in retinal image size with increasing distance.

**statement (framework)** — category: geometric size length; perceptual mechanism(s): misapplied-size-constancy, depth-cue-conflict.
