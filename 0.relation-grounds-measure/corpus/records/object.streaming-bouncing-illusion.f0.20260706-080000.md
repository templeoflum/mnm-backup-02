**statement (plain)** — The Streaming/Bouncing Illusion is a bistable motion perception phenomenon in which two identical objects moving toward each other, passing through the same spatial location, and then moving apart can be perceived in two qualitatively different ways: either as streaming through each other without interaction, or as bouncing off each other upon contact. The visual stimulus alone is inherently ambiguous and compatible with both interpretations. Remarkably, the perceptual interpretation can be strongly biased by cross-modal factors, particularly the presentation of a brief auditory stimulus synchronized with the moment when the objects overlap spatially.
