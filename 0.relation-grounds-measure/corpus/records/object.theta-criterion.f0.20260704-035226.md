**statement (plain)** — a bijection law for sentence structure: every argument a predicate takes must receive exactly one semantic role, and every role the predicate has to give must land on exactly one argument. Sentences that break the pairing are ungrammatical; adjuncts stand outside it.

**statement (formal)** — verbatim (Chomsky 1981:36): "Each argument bears one and only one θ-role, and each θ-role is assigned to one and only one argument." A filter on D-structure. The roles a predicate assigns are listed as its theta grid (Williams 1981): give = ⟨Agent, Theme, Goal⟩. **[confirmed]**

**basis** — the Government–Binding formalization of the thematic-role tradition ([[object.thematic-roles]]); note the grain distinction the dive carries: an argument bears one theta *role* but may carry multiple thematic *relations* (a single NP can be both Agent and Source).
