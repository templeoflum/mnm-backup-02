**statement (plain)** — The ordinals are well-ordered, so the set of all ordinals would itself have an ordinal number, Ω. But Ω is an ordinal, so Ω belongs to the set and Ω < Ω+1 ≤ Ω — the ordinal of all ordinals is greater than itself. Contradiction.

**statement (framework)** — the **earliest** modern set-theoretic paradox (predating Russell's), signalling that Cantor's naive theory was unstable and helping force axiomatization (there is no *set* of all ordinals in ZFC). Proven.
