**statement (plain)** — The T illusion is a simple yet robust geometric illusion in which a vertical line segment bisecting a horizontal line segment of equal length appears longer than the horizontal component. The stimulus configuration resembles an inverted T or plus sign, with the vertical element systematically overestimated in length relative to the horizontal element by approximately 10-20 percent in typical viewing conditions. The T illusion is considered a specific manifestation of the more general vertical-horizontal illusion, in which vertical extents are perceived as longer than equal horizontal extents.

**statement (framework)** — category: geometric size length; perceptual mechanism(s): orientation-selectivity, spatial-filtering.
