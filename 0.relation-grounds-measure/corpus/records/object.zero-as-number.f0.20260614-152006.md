**statement (plain)** — zero is not just a gap held open in a column; it is a number you can add, subtract, and multiply like any other. Brahmagupta was the first to write down rules for it: adding or subtracting zero leaves a number unchanged, and anything times zero is zero. Promoting zero from placeholder to full number is what lets the place-value system carry arithmetic cleanly.

**statement** — zero is the additive identity: for any number a, a + 0 = a and a − 0 = a; a · 0 = 0. Brahmagupta defined zero as "the result of subtracting a number from itself" and gave these rules together with rules for negatives ("fortunes" and "debts"), e.g. a debt subtracted from zero is a fortune. His one error: he treated division by zero as yielding a fraction with zero denominator and asserted 0 ÷ 0 = 0 — incorrect by modern lights (division by zero is undefined). **[confirmed]**

**basis** — the additive-identity and annihilation rules (a+0=a, a·0=0) are the defining properties that make zero a number rather than a mark; they are exactly what a positional system needs so that an empty column behaves arithmetically (see [[object.positional-notation]]). The division-by-zero rule is excluded because no number times zero gives a nonzero result, so the quotient cannot be defined.

**lineage** — a **zero placeholder** (empty-column mark, not a number) appears earlier: the Babylonian sexagesimal system added an empty-position symbol in later Babylonian times [[source.mactutor-babylonian-numerals]]. The **first systematic arithmetic of zero as a number** is Brahmagupta's *Brāhmasphuṭasiddhānta*, composed 628 CE at Bhillamala (25 chapters) [[source.brahmagupta-628]]. The first undisputed written zero glyph in India is the Gwalior inscription, 876 CE. Transmission of the operative zero into the wider system: al-Khwārizmī (c. 825) [[source.al-khwarizmi-825]] and Fibonacci, *Liber Abaci* (1202) [[source.fibonacci-1202]].
