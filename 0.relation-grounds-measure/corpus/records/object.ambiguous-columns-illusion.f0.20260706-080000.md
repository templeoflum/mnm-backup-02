**statement (plain)** — The Ambiguous Columns Illusion is a bistable perceptual phenomenon in which a visual depiction of columns or cylindrical forms spontaneously alternates between appearing convex (protruding outward) and concave (recessed inward). This ambiguity arises from conflicting depth cues in the stimulus, particularly shading gradients that can be interpreted as either illumination from above revealing convex surfaces or illumination revealing concave surfaces. The visual system typically assumes light comes from above, but when this assumption is challenged or when the stimulus provides insufficient disambiguating information, perception alternates between the two competing interpretations.

**statement (framework)** — category: ambiguous bistable multistable; perceptual mechanism(s): depth-cue-conflict, bistable-competition.
