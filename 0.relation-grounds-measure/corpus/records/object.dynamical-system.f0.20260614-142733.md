**statement (plain)** — a dynamical system is a phase space (the set of all possible states) together with a deterministic rule that says, given a state and an amount of elapsed time, exactly which state you reach. If time runs continuously you have a flow; if it ticks in whole steps you have a map you iterate. The rule depends only on elapsed time, never on the clock's absolute reading.

**statement (formal)** — a dynamical system is a triple (T, X, Φ) where X is the phase space, T is the time set (a monoid: ℝ or ℝ≥0 for continuous time, ℤ or ℕ for discrete time), and Φ : U ⊆ T × X → X is the evolution map satisfying the two flow axioms:
- identity: Φ(0, x) = x for all x,
- semigroup / composition: Φ(t₂, Φ(t₁, x)) = Φ(t₁ + t₂, x) whenever both sides are defined.
A continuous-time system is a **flow**, typically generated by a vector field ẋ = f(x); a discrete-time system is the iteration of a single **map**, Φⁿ = Φ ∘ ⋯ ∘ Φ. **[confirmed]**

**lineage** — the qualitative/geometric study of trajectories in [[phase space]] originates with [[Henri Poincaré]]'s celestial-mechanics work (1880s *Sur les courbes définies par une équation différentielle*; 1890 three-body memoir [[source.poincare-1890]]). [[George David Birkhoff]] abstracted it into a general theory in *Dynamical Systems* (1927) [[source.birkhoff-1927]]. The tuple-with-flow-axioms presentation is the modern textbook standard (Strogatz [[source.strogatz-nonlinear]]; Hirsch–Smale–Devaney [[source.hirsch-smale-devaney]]). **[confirmed]**
