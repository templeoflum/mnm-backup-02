U. Eco, *The Search for the Perfect Language* (Blackwell, 1995). **[confirmed]**

Role — the semiotic-structural reading of Kabbalistic letter-combination, Lull's *ars combinatoria*, and their successors as attempts to map metaphysical connection via a finite set of primary elements recombined; connects Lull to Leibniz's symbolic logic; ridicules Kircher's hieroglyphic "translations."
