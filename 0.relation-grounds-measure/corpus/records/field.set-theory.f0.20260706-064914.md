**origin** — Georg Cantor (from 1874) — the theory of infinite sets, cardinality, and the transfinite; the diagonal argument (1891) proving the reals uncountable. [[source.cantor-1891]]

**codification** — the axiomatization forced by the paradoxes (Russell's, Burali-Forti's): Zermelo (1908) and Zermelo–Fraenkel with Choice (ZFC), the standard foundation. Russell's paradox [[source.russell-1903]] is the pivot from naive to axiomatic set theory.

**door** — Herbert Enderton, *Elements of Set Theory* (or Halmos, *Naive Set Theory*) — cardinals, ordinals, the axioms.

*grade s — origin (Cantor), codification (Zermelo/ZFC via the paradoxes), door (Enderton) present. New field-home for the thought-experiments intake (quarantine, 20260706); homes the set/infinity cluster (diagonal argument, Russell's & Burali-Forti's paradoxes, Banach–Tarski, Hilbert's hotel).*
