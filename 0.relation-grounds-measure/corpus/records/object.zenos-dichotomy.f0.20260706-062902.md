**statement (plain)** — To walk to the door you must first reach the halfway point; but first the quarter, and first the eighth, and so on without end. The required preliminary motions never bottom out — there is no first step to take, since every step demands a prior one. So motion cannot even begin.

**statement (framework)** — where the Achilles challenges whether an infinite process can be *completed*, the Dichotomy (regressive form) challenges whether it can be *initiated* — whether a task with infinitely many prerequisite subtasks can have a first member. Forces confrontation with the structure of the continuum and the start of supertasks. Established; **open**.
