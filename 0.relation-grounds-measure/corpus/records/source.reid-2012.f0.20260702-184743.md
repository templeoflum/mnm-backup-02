Chris R. Reid, Tanya Latty, Audrey Dussutour, and Madeleine Beekman, "Slime mold uses an externalized spatial 'memory' to navigate in complex environments," *PNAS* 109, no. 43 (2012): 17490–17494.

Contains — *Physarum polycephalum*, which has no brain or neurons, lays extracellular slime everywhere it has been and *avoids* areas already coated, using the trail as an external spatial map to solve the U-shaped trap (a standard robot-navigation test). Effect size: on blank substrate ~96% reached the goal (~macro 60 h); on slime-pre-coated substrate (masking the organism's own trail) only ~1/3 reached it, slower, re-traversing explored areas >10× as often. The authors propose externalized spatial memory as a possible "functional precursor to the internal memory of higher organisms" — a clean case of memory-without-learning and externalized (non-neuronal) cognition.
