D. Dowty, "Thematic Proto-Roles and Argument Selection," *Language* 67(3), 547–619 (1991).

Role — rejects a fixed list of discrete thematic roles for two cluster-concepts, Proto-Agent and Proto-Patient, each a set of lexical entailments; the Argument Selection Principle maps entailment counts to subject/object. Critical retrospective: B. Levin, "On Dowty's 'Thematic Proto-Roles and Argument Selection'" (Springer volume, 2021/2022). **[confirmed]**
