**statement (plain)** — Fisher's Figure is an ambiguous visual stimulus created by psychologist Gerald H. Fisher that can be perceived as two distinct three-dimensional objects depending on how the viewer organizes the visual information. The figure demonstrates principles of depth ambiguity and perceptual organization, where the same line configuration can be interpreted in multiple ways based on different assumptions about which surfaces are in front and which are behind, or how various contours connect to form coherent objects.

**statement (framework)** — category: ambiguous bistable multistable; perceptual mechanism(s): bistable-competition, depth-cue-conflict.
