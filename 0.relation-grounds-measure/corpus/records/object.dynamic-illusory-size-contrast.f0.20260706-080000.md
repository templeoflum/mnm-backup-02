**statement (plain)** — The Dynamic Illusory Size-Contrast Effect, commonly abbreviated as the DISC Effect, is a motion-induced size illusion in which dynamic changes in the surrounding visual context produce systematic misperceptions of target size. When a target stimulus is presented against a background of expanding or contracting elements, the target appears to change in size in the direction opposite to the context motion, even when the target itself remains physically constant in size. For example, a circle surrounded by an expanding pattern appears to shrink, while the same circle surrounded by a contracting pattern appears to grow.
