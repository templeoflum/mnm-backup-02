**statement (plain)** — The Ambiguous Cylinder Illusion, created by mathematician and artist Kokichi Sugihara, is a striking three-dimensional optical illusion in which specially constructed physical objects appear to have one shape when viewed directly but appear as a completely different shape when viewed through a mirror reflection. The most famous version features objects that appear as circular cylinders when viewed directly but transform into square columns when seen in a mirror, or vice versa. This seemingly impossible transformation is achieved through careful construction of three-dimensional forms with cross-sections that are highly asymmetric and precisely calculated to produce different silhouettes from different viewing angles.
