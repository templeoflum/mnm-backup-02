**statement (plain)** — A bat perceives by echolocation, a sensory world alien to ours. We could map every neuron and model the sonar processing completely — yet still not know *what it is like* to perceive by echolocation. There is something it is like to be a bat, and objective science, which abstracts away from any point of view, cannot reach it.

**statement (framework)** — the classic statement that **phenomenal consciousness** (qualia) is tied to a point of view and so resists reductive, objective explanation — a principled, not merely practical, limit. Directly seeded Levine's *explanatory gap* (1983), Chalmers's *hard problem* (1995), and Jackson's Mary's Room (1982). Established; the reducibility of consciousness stays **open**.
