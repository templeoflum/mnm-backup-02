**statement (plain)** — The Telescope Effect refers to the perceptual paradox whereby objects viewed through magnifying optical instruments such as telescopes or binoculars appear simultaneously closer in depth yet smaller in perceived size than expected, violating the normal coupling between distance and size perception. When observers view a distant object through a telescope, the magnified retinal image provides strong cues that the object is nearby, triggering depth perception mechanisms that signal reduced distance. However, because the object's magnified angular size may still be smaller than anticipated for an object at close range, or because conflicting depth cues indicate the object's true far distance, the visual system experiences a conflict between size and distance information.
