Heinrich Wilhelm Olbers (1823) — poses the dark-night-sky paradox: in an infinite, eternal, uniform universe every sightline should end on a star, so the sky should blaze; that it does not encodes the universe's finite age and expansion. **[confirmed as attribution]**
