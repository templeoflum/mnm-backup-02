**statement (plain)** — The Necker Cube, discovered by Swiss crystallographer Louis Albert Necker in 1832, is a wireframe drawing of a cube that spontaneously reverses its apparent depth orientation during sustained viewing. This classic ambiguous figure can be perceived with either the lower-left square or the upper-right square appearing as the front face, with the entire three-dimensional interpretation flipping between these two configurations every few seconds. The illusion occurs because the two-dimensional line drawing lacks definitive depth cues that would specify which interpretation is correct, allowing the visual system to construct two equally valid three-dimensional percepts from the same retinal input.
