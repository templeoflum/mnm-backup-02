**statement (plain)** — The numerosity adaptation effect demonstrates that the visual system's representation of number is subject to adaptation, analogous to adaptation for low-level features like orientation and motion. After prolonged exposure to displays containing a large number of elements (e.g., many dots), a subsequently viewed display with a moderate number of elements is perceived as containing fewer items than it actually does. Conversely, adaptation to sparse displays causes moderate-numerosity displays to appear more numerous.

**statement (framework)** — category: aftereffect adaptation; perceptual mechanism(s): neural-adaptation.
