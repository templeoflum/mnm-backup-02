**statement (plain)** — Shepard's Elephants is an impossible figure created by cognitive scientist Roger Shepard depicting elephants where the legs and the spaces between legs are perceptually ambiguous and mutually incompatible. The illustration typically shows a row of elephants where careful examination reveals that it is impossible to determine which gray regions represent solid elephant legs versus which regions represent empty spaces between the legs. The figure exploits figure-ground segregation processes, where the visual system must determine which areas of an image correspond to objects versus background.

**statement (framework)** — category: impossible objects paradox; perceptual mechanism(s): figure-ground-segregation, contour-integration, depth-cue-conflict.
