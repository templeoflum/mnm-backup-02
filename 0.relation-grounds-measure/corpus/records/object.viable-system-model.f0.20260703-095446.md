**statement (plain)** — Beer's model says any organization that survives in a changing environment must contain five kinds of function, and each viable unit recursively contains smaller viable units built the same way. System 1 does the primary work (operations); System 2 coordinates and damps oscillation between them; System 3 controls and allocates internally; System 4 looks outward and to the future (intelligence, adaptation); System 5 sets identity and policy. Viability is having enough regulatory variety, distributed across these functions, to absorb the environment's variety.

**basis** — the model is Ashby's Law of Requisite Variety ([[object.law-of-requisite-variety]]) engineered into organizational form, plus recursion (viable systems nest within viable systems) [[source.beer-1972]] **[confirmed]**. Founded management cybernetics.

**relevance** — the organizational instance of HOLD: how a directed collective enterprise keeps itself coherent against disturbance by matching variety with variety, rather than by central command alone.
