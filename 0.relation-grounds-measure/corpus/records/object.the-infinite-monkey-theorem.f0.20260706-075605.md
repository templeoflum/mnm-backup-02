**statement (plain)** — A monkey hitting random keys forever will, with probability one, eventually type the complete works of Shakespeare. Formally: in an infinite sequence of independent uniform draws from a finite alphabet, any fixed finite string occurs as a substring almost surely.

**statement (framework)** — a **proven theorem** (a corollary of the second Borel–Cantelli lemma): infinitely many independent chances make any positive-probability event almost certain. Borel's point was pedagogical — the vast gulf between mathematically certain and physically realizable (the expected wait is astronomically longer than the universe's age). Proven.

**basis** — Borel's typing-monkeys illustration (1913) [[source.borel-1913]]; via the Borel–Cantelli lemma. **[confirmed as attribution]**
