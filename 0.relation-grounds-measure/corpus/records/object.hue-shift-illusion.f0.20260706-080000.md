**statement (plain)** — The hue shift illusion encompasses a class of chromatic induction phenomena in which the perceived hue of a target region shifts systematically as a function of the chromaticity of surrounding or adjacent regions. This effect demonstrates that color perception is fundamentally contextual, with the visual system computing local color appearance through interactions between neighboring chromatic signals rather than processing wavelength information in isolation. The magnitude and direction of hue shifts depend on multiple factors including the chromatic distance between target and inducing regions, spatial configuration, temporal dynamics, and luminance relationships.
