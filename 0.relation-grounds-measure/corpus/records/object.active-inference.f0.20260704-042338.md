**statement (plain)** — if a system minimizes surprise, one way is to change its mind (perception); the other is to change the world so the prediction comes true (action). Active inference is that second arm: you predict the proprioceptive consequences of moving, and moving fulfills the prediction. Behavior becomes self-fulfilling inference.

**basis** — the action side of the free-energy principle ([[object.free-energy-principle]]); Constant, Clark, Kirchhoff & Friston (2020) extend it outward as "extended active inference" — cognitive niche construction as optimizing the generative model, with "cognitive uploading" installing new functions in the niche.
