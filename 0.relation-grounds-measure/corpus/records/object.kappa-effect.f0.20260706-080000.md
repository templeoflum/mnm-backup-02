**statement (plain)** — The kappa effect is a temporal illusion in which the perceived duration of time intervals between sequential events is systematically influenced by the spatial separation between those events. Specifically, when two events are separated by a greater spatial distance, the temporal interval between them is perceived as longer than when the same objective time interval separates spatially closer events. This effect demonstrates a fundamental interdependence between spatial and temporal perception, revealing that the brain does not process space and time as independent dimensions but instead integrates them according to implicit assumptions about typical spatiotemporal regularities in the environment.
