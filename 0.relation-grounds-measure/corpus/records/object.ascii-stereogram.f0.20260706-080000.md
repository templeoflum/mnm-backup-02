**statement (plain)** — ASCII stereograms are text-based three-dimensional images created using standard ASCII characters arranged in side-by-side pairs that, when viewed with appropriate binocular fusion techniques such as cross-viewing or parallel viewing, produce vivid depth perception. These stereograms exploit binocular disparity, the fundamental cue underlying stereoscopic vision, by presenting slightly different character patterns to each eye. The horizontal displacement between corresponding characters in the left and right halves of the stereogram mimics the retinal disparity that normally arises from viewing three-dimensional objects from two slightly separated viewpoints.
