**statement (plain)** — the classical art: impress a series of "places" (*loci*) — a remembered building, a route — and set vivid "images" for the matter to be recalled at each; recall walks the places in order. Yates: "the manipulation of images in memory must always, to some extent, involve the psyche" — the art forms a navigable internal architecture. **[confirmed]** *(status `established` — a documented, working technique.)*

**basis** — the three Latin sources; medieval transmission under Prudence (Albertus, Aquinas); Renaissance occult memory as lineage: Camillo's Memory Theatre (*L'Idea del Theatro* — the inverted amphitheatre aspiring to total knowledge), Lull's combinatorial art treated as memory art, Bruno's Hermetic mnemonics (*De umbris idearum*, astral memory-images).
