**statement (plain)** — Colon Classification (CC) is the first library classification system built on facets instead of one fixed list of subjects. Rather than looking your subject up in an exhaustive enumerated list, you pick concepts from separate facets and string them together — in the PMEST order — to construct a class number that exactly fits the subject. It is named for the colon, which was originally the single symbol used to join the facets.

**statement** — Colon Classification is "an analytico-synthetic as opposed to an enumerative classification system." Where an enumerative scheme gives a top-down exhaustive list of subjects, CC "lists concepts which are to be combined in a pre-set order, to construct a class number co-extensive with the subject." Facets are joined by connecting symbols; in the original scheme the colon was the only connecting symbol, giving the system its name. The facet (citation) order follows [[object.pmest-fundamental-categories]] (P : M : E : S : T). **[confirmed]**

**basis** — CC operationalizes [[object.facet-analysis]] (the analytical step) plus synthesis of the resulting facets into one notation (see [[object.analytico-synthetic-classification]]); PMEST supplies the postulated category set and the citation order. The single-colon notation was a known weak point — an inadvertent extra colon could misplace a book — and later editions introduced distinct connecting symbols. **[confirmed]**

**lineage** — created by S. R. Ranganathan (1892–1972); "conceived and initially developed from 1924 to 1928" and first published in 1933 [[source.ranganathan-1933]]; theory companion *Prolegomena to Library Classification* (1937) [[source.ranganathan-1937]]. Seven editions were published between 1933 and 1987; the 4th edition (1952) introduced the PMEST "five and only five" postulate. It is widely cited as the first faceted / analytico-synthetic classification system. **[confirmed]** — the 1924–1928 development dates rest on a single ISKO statement and Ranganathan's own account; **[candidate, dating]** on the precise development window.
