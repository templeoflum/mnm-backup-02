**statement (plain)** — One can build the natural numbers out of sets in many ways: von Neumann's (0=∅, 1={∅}, 2={∅,{∅}}, …), Zermelo's (0=∅, 1={∅}, 2={{∅}}, …), and endlessly more. Each does everything arithmetic needs, yet they disagree on facts like "is 2 a member of 3?" If numbers *were* particular sets, exactly one account would be correct — but nothing could make one correct rather than another. Benacerraf concludes numbers are not objects at all; what matters is only the *structure* (the progression) they occupy.

**consequences** — the argument that motivates structuralism: if arithmetic truth is invariant across all its set-theoretic realizations, then it is about the shared structure, not the objects. Sets up the structuralist thesis that numbers are **positions in a structure** ([[object.ante-rem-structuralism]]) rather than self-standing things [[source.benacerraf-1965]] **[confirmed]**.
