**statement (plain)** — The Color Assimilation Grid Illusion is a striking chromatic phenomenon in which a grayscale image overlaid with a colored grid of fine lines appears to contain the full spectrum of grid colors, despite the underlying image containing no chromatic information. The illusion became widely known through viral social media demonstrations showing black-and-white photographs that appear fully colored when viewed through a sparse colored grid overlay. The effect is strongest when the grid lines are thin, the spacing is optimized relative to viewing distance, and the colored lines align with or follow the contours of objects in the image.
