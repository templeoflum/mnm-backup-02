**statement (plain)** — The size aftereffect is an adaptation phenomenon in which prolonged viewing of objects of a particular size causes subsequently viewed objects to appear shifted in size in the opposite direction. After adapting to large objects or stimuli, test objects of moderate size appear smaller than baseline, while adaptation to small objects makes test stimuli appear larger. The effect operates across various stimulus types including simple geometric shapes, spatial frequency gratings, and complex objects.

**statement (framework)** — category: aftereffect adaptation; perceptual mechanism(s): neural-adaptation, spatial-filtering.
