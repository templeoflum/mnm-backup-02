**statement (plain)** — In a structural set theory such as Lawvere's **ETCS** (Elementary Theory of the Category of Sets), a set is characterized only by its elements-and-functions structure, and an element x ∈ S has no properties beyond being an element of that particular set — there is no global membership relation asking whether one set is "inside" an unrelated one, as ZFC's ∈ allows. Sets and functions are axiomatized as a category (a well-pointed topos with a natural-numbers object and choice), so mathematics rests on how objects map to one another rather than on what they are "made of."

**significance** — the concrete mathematical realization of structuralism: it treats sets the way ante rem structuralism treats numbers — as positions/roles, not stuffed objects — and is offered as an alternative foundation to material (ZFC) set theory. McLarty argues it dissolves Benacerraf's identification problem ([[object.benacerraf-identification-problem]]).
