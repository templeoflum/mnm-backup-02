**statement (plain)** — Subjective Constancy refers to the perceptual system's fundamental tendency to maintain stable, invariant percepts of object properties despite continuous changes in proximal sensory stimulation. This general principle encompasses multiple specific constancy phenomena, including size constancy (objects appear stable in size despite changing retinal image size with distance), brightness constancy (surface reflectance appears stable despite illumination changes), color constancy (object colors appear stable across different lighting conditions), and shape constancy (three-dimensional form appears stable across viewpoint changes). Subjective constancy represents one of perception's most remarkable achievements, solving the inverse problem of inferring stable distal properties from variable proximal signals.
