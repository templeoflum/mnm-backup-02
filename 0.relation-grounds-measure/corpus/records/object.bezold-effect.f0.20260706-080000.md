**statement (plain)** — The Bezold Effect is a chromatic illusion in which the perceived color of a region changes substantially when small interspersed elements of a different color are introduced or altered, causing the target region to assimilate toward the color of the fine details. This phenomenon represents color assimilation rather than color contrast: unlike simultaneous color contrast where adjacent regions shift away from each other in color space, the Bezold Effect causes shifts toward the inducing color. Wilhelm von Bezold, a 19th-century physicist and textile designer, discovered the effect in 1876 while working with woven fabrics and tapestries, where fine threads of one color dramatically altered the appearance of the overall pattern.
