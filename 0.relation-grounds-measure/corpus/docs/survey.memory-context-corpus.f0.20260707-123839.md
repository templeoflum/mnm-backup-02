## 1 · external memory & extended cognition — the body-as-memory idea
- **object.exogram** — an external memory record (Donald), contrasted with the internal engram; longer-lasting, reformattable
- **object.extended-mind-thesis** — cognitive processes and even mental states can be partly *constituted* by external resources (Clark & Chalmers)
- **object.distributed-cognition** — the unit of analysis is the whole functional system of people + artifacts + environment, not the head
- **object.functional-system** — the bounded assembly of agents, artifacts, and representations that does the cognitive work
- **object.complementarity-principle** — external and internal resources differ in kind yet make a joint system (second-wave EM)
- **object.parity-principle** — an external process counts as cognitive if an equivalent internal one would
- **object.situated-action** — plans are resources for action, not the structure of it; action is situated
- **object.slime-mold-externalized-memory** — a brainless organism navigates by reading its own deposited trail — memory offloaded to the world (stigmergy-kin)

## 2 · non-linear notes & the slip-box — networked, addressed, emergent
- **object.zettelkasten-slip-box** — a networked slip-box of atomic, addressed notes acting as a thinking partner
- **object.atomic-note** — one self-contained idea per note, in your own words — the unit that makes precise linking possible
- **object.linking-emergent-structure** — order emerges bottom-up from cross-references + a keyword register, not top-down taxonomy
- **object.fixed-branching-address** — every note gets a permanent unique number that never changes, abstracted from topic (Luhmann's addressing)
- **object.namespace** — a bounded set of names where each resolves to at most one thing — context that disambiguates

## 3 · memory mechanics — encoding, forgetting, reconstruction
- **object.seven-sins-of-memory** — Schacter's taxonomy of memory failures (transience, absent-mindedness, blocking, misattribution, …)
- **object.reconstructive-memory** — remembering is rebuilding from fragments under present bias, not replaying a trace
- **object.memory-reconsolidation** — a retrieved memory becomes labile again and must re-stabilize — recall *rewrites*
- **object.nader-2000** — Nader–Schafe–LeDoux: reactivated fear memories return to a labile state (the reconsolidation evidence)

## 4 · the art of memory — deliberate mnemonic architecture
- **object.method-of-loci** — impress images at places in a remembered architecture, walked to recall in order
- **object.ars-combinatoria** — Lull's revolving wheels recombining a finite alphabet of notions — generative memory

## 5 · knowledge organization & classification — faceted structure
- **object.analytico-synthetic-classification** — analyse a subject into facets, synthesize a class number from them
- **object.facet-analysis** — sort a subject's terms into homogeneous, mutually exclusive facets
- **object.colon-classification** — the first faceted library classification (Ranganathan) — class numbers built, not looked up
- **object.pmest-fundamental-categories** — five and only five fundamental categories: Personality, Matter, Energy, Space, Time

## 6 · archival appraisal & lifecycle — deciding what to keep, and forgetting by design
- **object.appraisal** — judging which records have enough enduring value to keep, and for how long (forgetting as a discipline)
- **object.records-lifecycle** — records pass sequential stages: creation → active → semi-active → final disposition
- **object.records-continuum** — recordkeeping as four concurrent recursive dimensions, not sequential stages
- **object.provenance** — keep records grouped by their creator, never intermix fonds of different origin
- **object.original-order** — keep records in the arrangement their creator gave them (respect pour l'ordre)
- **object.fonds** — the whole body of records organically created by one creator

## 7 · naming & addressing — how a thing is found again
- **object.content-addressable-storage** — the name IS the hash of the content; identity from content, not location
- **object.hierarchical-naming-dns-resolution** — a global namespace as a tree of delegated zones, resolved by walking it
- **object.positional-notation** — a digit's value depends on its position (the lattice's own addressing kin)
- **object.uri-generic-syntax** — the standard grammar of a web address (scheme/authority/path/query/fragment)
- **object.godel-numbering** — a reversible encoding assigning each symbol/formula/proof a unique number
- **object.fixed-branching-address** — (see §2) permanent unchanging note-addresses

## 8 · salience & signal — what carries the information (already grounded for clerk's skimmer)
- **object.tf-idf** — term weight = frequency here × rarity across the collection — the core "which words matter"
- **object.bm25** — the probabilistic ranking refinement of tf-idf (saturation + length normalization)
- **object.shannon-entropy** — average uncertainty in bits — a word's surprise IS its information
- **object.source-coding-theorem** — entropy is the exact floor on lossless compression (keep the informative, drop the rest)
- **object.mutual-information** — the bits two variables share — context relevance
- **object.kullback-leibler-divergence** — extra bits paid for coding with the wrong model — distributional shift
- **object.self-similarity-of-language** — Zipf / long-range dependence: high-frequency words carry the least info (the strip gradient)
- **object.vector-space-model** · **object.cosine-similarity** — represent + compare notes as vectors (semantic recall)

## 9 · attention allocation & cognitive search — where to look, when to move on
- **object.explore-exploit-tradeoff** — exploit a known-good source vs explore alternatives — the attention economy in one line
- **object.marginal-value-theorem** — leave a depleting patch when its marginal return falls to the environment average
- **object.area-restricted-search** — search locally while productive, jump when returns drop
- **object.adaptive-gain-theory** — the LC–norepinephrine system implements explore/exploit neurally
- **object.inattentional-blindness** — the failure to see the clearly visible when attention is elsewhere (the cost of a full window)

## 10 · curation for a corpus — building & maintaining the store
- **object.data-curation** — systematic construction, documentation, cleaning, maintenance of a dataset
- **object.data-quality-principle** — for a fixed model, better data beats more tuning
- **object.datasheets-for-datasets** — a standardized documentation record accompanying a dataset
- **object.training-data-deduplication** — remove exact + near-duplicate content to improve the store and cut waste

## gaps — what the house does NOT hold yet (flat, for the sift)
The corpus holds the **frameworks** (extended mind, the slip-box, appraisal, salience, addressing) but not the core **memory-encoding/forgetting mechanics** as objects: no `spacing-effect`, `testing-effect`, `forgetting-curve` (Ebbinghaus), `desirable-difficulties`, `chunking`, `spreading-activation`, `serial-position`, `levels-of-processing`, `cue-dependent-retrieval`. If the design leans on *how memory is encoded and decays*, those are a small intake away — named here, not decided.
