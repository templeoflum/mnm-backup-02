**statement (plain)** — when one option is set as the default (what happens if the chooser takes no action), people select it far more often than they would if every option required active choice. The effect holds even when the stakes are large and switching is cheap. Mechanisms commonly cited: inertia / effort cost, the default read as an implicit recommendation, and loss aversion relative to the default as reference point.

**basis** — empirical. Support: [[source.madrian-shea-2001]] — automatic (opt-out) 401(k) enrollment raised participation sharply versus opt-in, and most auto-enrolled employees stayed at the default contribution rate and fund, outcomes almost no one chose actively. Cross-domain: organ-donation consent rates differ dramatically between opt-in and opt-out countries (Johnson & Goldstein 2003), and the default effect is the headline mechanism in [[source.thaler-sunstein-2008]] *Nudge*. Limits: magnitude is domain-dependent; defaults can entrench bad choices as easily as good ones; the effect interacts with how strongly the default is read as advice and whether active choice is forced. **[confirmed]**

**sources** — [[source.madrian-shea-2001]] (the canonical field demonstration), [[source.thaler-sunstein-2008]] (synthesis + organ-donation case). Verified against QJE/NBER records and Wikipedia "Default effect" / "Nudge theory." **[confirmed]**
