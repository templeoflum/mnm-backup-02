Verbatim citation:

Dorigo, M. (1992). *Optimization, Learning and Natural Algorithms* (in Italian). PhD thesis, Dipartimento di Elettronica, Politecnico di Milano, Milan, Italy.

Contains: the doctoral thesis in which Dorigo first proposed ant-colony optimization, introducing the algorithm later named the Ant System. The method has artificial ants build solutions to a combinatorial problem (e.g., a path in a graph) while depositing and following artificial "pheromone," an explicit computational stigmergy: the shared pheromone matrix is the modified environment through which independent agents coordinate. [confirmed]
