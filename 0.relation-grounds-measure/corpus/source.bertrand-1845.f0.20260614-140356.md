Full citation — J. Bertrand, "Mémoire sur le nombre de valeurs que peut prendre une fonction quand on y permute les lettres qu'elle renferme," *Journal de l'École Royale Polytechnique*, cahier 30, vol. 17 (1845). The postulate arose as a lemma needed for this work on permutation groups.

Contains the conjecture (the "postulate") that for every integer n > 1 there is a prime p with n < p < 2n. Bertrand verified it numerically for n up to ~3,000,000 but did not prove it.

Role — the conjecture source for [[object.bertrands-postulate]] (distinct from the proof source, Chebyshev 1852).

Access — historical; the conjecture is universally attributed to Bertrand (1845). **[confirmed as attribution]**
