**statement (plain)** — the SI fixes seven base units — second, metre, kilogram, ampere, kelvin, mole, candela — as the foundation of measurement. Every other unit (newton, volt, watt, …) is built as a product of powers of these seven. Since 2019 each base unit is no longer a separate definition but a consequence of seven fixed constants of nature.

**statement (precise)** — the SI base quantities and their units are: time / **second** (s), length / **metre** (m), mass / **kilogram** (kg), electric current / **ampere** (A), thermodynamic temperature / **kelvin** (K), amount of substance / **mole** (mol), and luminous intensity / **candela** (cd). All other SI units are coherent derived units formed as products of powers of the base units with no numerical factor other than one. **[confirmed]**

**status** — in force. The set of seven base units has been stable since the SI was named in 1960; the *definitions* were re-expressed in 2019 in terms of the [[object.si-defining-constants]].

**lineage** — the name "Système International d'Unités" (SI) and the first six base units were adopted by the 11th [[source.cgpm-1960]] (Resolution 12, 1960), building on the MKS/metre-kilogram-second tradition rooted in the [[source.metre-convention-1875]]. The mole was added as the seventh base unit by the 14th CGPM (1971). The current authoritative statement is the BIPM *SI Brochure*, 9th ed. [[source.si-brochure-2019]], with the US edition [[source.nist-sp330-2019]]. **[confirmed]**
