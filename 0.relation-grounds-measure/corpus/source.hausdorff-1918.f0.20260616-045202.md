F. Hausdorff, "Dimension und äußeres Maß," *Mathematische Annalen* **79** (1918), 157–179. DOI 10.1007/BF01457179.

Contains — defines, for each non-negative real parameter, an outer measure (the Hausdorff measure) on a metric space via coverings of bounded diameter; observes that there is a critical value of the parameter at which the measure jumps from ∞ to 0, and that this critical value — taking arbitrary non-negative real values, not just integers — behaves as a dimension. This is the measure-theoretic foundation of "fractal dimension."
