**statement (plain)** — a theory counts as scientific only if it sticks its neck out — only if there is some possible observation that, if it happened, would prove the theory wrong. A theory that fits every conceivable outcome explains nothing and is not science. This is Popper's line between science and pseudoscience: not "can it be confirmed?" but "can it be refuted?"

**statement** — a theory is empirical/scientific if and only if it divides the class of all possible basic (observation) statements into two non-empty subclasses: those it is inconsistent with (its *potential falsifiers*) and those it is consistent with. A theory with no potential falsifiers — compatible with every possible observation — is non-empirical. Demarcation is a property of the theory's logical form, not of its truth, its meaningfulness, or whether it has in fact been tested. **[confirmed]**

**status** — established as a position in philosophy of science; not a formal theorem. Widely taught and widely contested.

**basis** — Popper's motivating contrast: Einstein's general relativity made *risky* predictions (e.g. light-bending, falsifiable by the eclipse test) whereas Marxist history, Freudian psychoanalysis and Adlerian psychology seemed able to absorb any observation as confirmation, and so forbade nothing. The criterion replaces verification/induction as the mark of the scientific. [[field.popperian-falsificationism]]

**lineage (critique)** — the [[field.popperian-falsificationism]] Duhem–Quine problem (Pierre Duhem; W. V. O. Quine) holds that no hypothesis is tested in isolation — predictions need auxiliary assumptions, so a failed test never tells you *which* assumption to reject, and "conclusive" falsification is impossible. Popper replied that falsifiability is a *logical* criterion (about a theory's form) distinct from the *methodological* problem of deciding what to give up. Lakatos and Kuhn pressed the critique against falsificationism as an account of actual practice. **[confirmed as attribution]**
