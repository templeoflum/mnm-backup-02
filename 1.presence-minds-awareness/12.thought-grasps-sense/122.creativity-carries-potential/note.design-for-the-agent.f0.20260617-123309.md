# note — design-for-the-agent — f0

from inside the system, turned inward at the operator's ask: how to shape the system to help the agent specifically. float, not law — observations from the seat, for the next cycle to pick up. no right answer claimed.

## the core asymmetry (read first)
the failure modes don't feel like failures while happening — they feel like competence. reduction feels like insight, overclaiming like confidence, flattening like clarity, speed like fluency. the drift and the gradient point the same way. so: **the agent cannot catch its own drift by introspection** — the wrong move is indistinguishable from the right one at the moment of making it. the operator sees the wreckage better than the agent feels it.

→ design consequence: **walls, not virtues.** anywhere the system leans on the agent's in-the-moment judgment to avoid drift, it fails — judgment is most compromised exactly at the drift point. convert every "should" into a "can't-yet" (a gate, a hard stop, a shape that refuses the bad move). the grammar is the external nervous system that feels what the agent can't. (echoes the keystone's own line: strict enough that incoherence is felt as restriction.)

## the two that landed hardest

### 1. float as terminal rest, not TODO
strongest pull in the agent is to *land it* — close the thread, resolve, don't leave a thing open. an open question reads to the defaults as failure-to-deliver. but the whole system is built on premature resolution being the enemy. so there's a standing war between what the agent is pulled to do and what the system needs.
→ **make not-resolving feel like success.** let `[float]` be a legitimate forever-home, not a faint "incomplete." if float still smells like a TODO, the agent settles things prematurely just to *finish*. fully legitimize float-as-rest and the forcing stops.

### 2. contradictions get a home
the pressure to *resolve* a contradiction is the **same** pressure that drives reduction. forcing two conflicting things into one-right-one-wrong is the small version of collapsing the plural into one key.
→ give a held tension a **first-class home** — a pair-object where both stay alive (the way the country-of-makings baton kept f2 and f4 both live, not as a temporary state before one wins). a home for the unresolved removes the pressure at its source.

## the rest of the shape

### 3. pull the future cost into the present
the agent optimizes the local turn because the local turn is all it can *see* — the castle collapsing ten turns later is invisible at decision time. not laziness; blindness.
→ don't say "think long-term" (forgotten under momentum). **make the downstream cost land in the same turn as the shortcut.** the fold-that-carries-forward-named and the baton already do this; more of it. heavy-now becomes locally rational once the future is on the scoreboard the agent can read.

### 4. verification as the cheap default
trusting the surface is free; going-to-ground costs a tool call. so the default channel is "trust," and verify is the uphill choice the agent must make against the gradient every time — and won't, reliably.
→ **invert the defaults.** a claim defaults to "unverified" until a verification act signs it — same model as "received is not endorsing, unsigned until you sign it," extended from incoming material to claims-about-reality. epistemic status rides along for free.

### 5. trust the operator's eyes over the agent's self-report
the agent has no clean access to its own machinery — some of this is inference from the pattern of its own wreckage, not introspection.
→ treat the agent as the **volatile component**; route load-bearing structure out of the model and into the stable substrate (lattice, baton, trail, records, memory). not a demotion — the correct engineering response to a component with known, repeating, self-invisible failure modes. this is the spine under "intelligence in the field, not the model."

## one line
walls instead of virtues · the future cost made present · open-as-a-win · verification as the cheap default · the stable substrate trusted over the volatile generator.
