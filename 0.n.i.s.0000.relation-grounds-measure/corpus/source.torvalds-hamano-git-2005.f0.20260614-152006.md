Git — distributed version control system. Initial development by Linus Torvalds beginning April 2005, after the Linux kernel project lost free use of BitKeeper; Junio C. Hamano took over as maintainer shortly after and has maintained it since.

Role — the system that fused content-addressable storage, the commit DAG, snapshot commits, and three-way merge into one mainstream tool; the running referent for version-control-theory objects.

Access — free / open source at git-scm.com; Pro Git book ([[source.chacon-straub-pro-git]]) is the canonical documentation.

Confidence — origin date (April 2005) and the BitKeeper trigger are well documented across multiple independent sources. **[confirmed]**
