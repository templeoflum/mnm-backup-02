R. L. Devaney, *An Introduction to Chaotic Dynamical Systems*, 2nd ed., Addison-Wesley (1989).

Source of "Devaney chaos": a map is chaotic on an invariant set if it is (1) sensitive to initial conditions, (2) topologically transitive, and (3) has dense periodic points. Later shown (Banks et al., 1992) that transitivity + dense periodic points imply sensitivity, so sensitivity is redundant on infinite metric spaces.

Distinct work from the Hirsch–Smale–Devaney ODE textbook (see [[source.hirsch-smale-devaney]]).

**[confirmed]** — definition corroborated by Wikipedia (Chaos theory) and standard dynamical-systems references; first edition 1986, second edition 1989.
