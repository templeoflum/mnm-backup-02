**citation** — Nelson Elhage, Tristan Hume, Catherine Olsson, Nicholas Schiefer, Tom Henighan, Shauna Kravec, Zac Hatfield-Dodds, Robert Lasenby, Dawn Drain, Carol Chen, Roger Grosse, Sam McCandlish, Jared Kaplan, Dario Amodei, Martin Wattenberg, and Christopher Olah. "Toy Models of Superposition." Transformer Circuits Thread, 2022. https://transformer-circuits.pub/2022/toy_model/index.html (also arXiv:2209.10652).

**contains** — builds small, fully-analyzable ("toy") models in which polysemanticity is precisely understood. Shows that when features are sparse, a network packs more features than it has dimensions by placing them in **superposition** — features stored as overlapping directions, accepting interference in exchange for capacity. Demonstrates a phase change governing when superposition occurs, a connection to the geometry of uniform polytopes, and a link to adversarial examples.
