Andrew Ng, DeepLearning.AI, and Landing AI, "Data-Centric AI Competition" (2021), https-deeplearning-ai.github.io/data-centric-comp; announced June 2021, following Ng's framing of a data-centric AI movement from March 2021.

Inverts the standard ML-competition format: the model architecture is fixed and competitors instead improve a dataset (fixing mislabeled examples, adding edge cases, augmenting) to raise downstream model performance. The organizing claim is that high-performance model architectures are now widely available while dataset-engineering practice has lagged, so the larger remaining gains come from systematically improving data rather than models.
