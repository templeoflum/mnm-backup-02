**statement (plain)** — instead of filing notes under subjects, Luhmann gave each card a fixed number that it kept forever (feste Stellordnung, "fixed-position ordering"). A new note that continues an idea branches off the one before it — 57/12 can be continued by 57/13, or branched by 57/12a — alternating numbers and letters so a card can sprout sub-branches indefinitely. The number says where a note sits in the web, not what it is about. Because the address is permanent, the card never has to move, and you can insert a new thought anywhere.

**statement** — Luhmann's key point: it matters more that you "have a fixed address to get from A to B" than where a note is physically placed. Fixed-place numbering, abstracted from content order, "permits free internal branching" — "a note with the number 57/12 can be continued with 57/13, but it could also be complemented ... with 57/12a." Branches alternate digits and letters (e.g. 1 → 1a → 1a1 → 1a1a), so each new card is inserted directly behind its parent and never reorganized. **[confirmed]**

**basis** — a structural design choice, not a proof. Its payoff is that a permanent address decouples a note's identity from any topical hierarchy: the box never needs reordering, branches can grow without limit, and stable addresses give links reliable targets — the precondition for [[object.linking-emergent-structure]]. Verified against the realized archive: Schmidt [[source.schmidt-2018]] documents the two card indexes (a first ~1952–1963 box and a second ~1963–1997 box, ~90,000 cards total) built on this scheme.

**lineage** — the principle is Luhmann's own, stated in the 1981 essay [[source.luhmann-1981]] and analyzed by Schmidt [[source.schmidt-2018]]; the Bielefeld Niklas-Luhmann-Archiv digital edition reproduces the numbered cards and their reference links. Branch-notation examples (1a, 1a1) are standard across the scholarship and community; specific composite IDs cited in popularizations (e.g. 21/3d…) are illustrative reconstructions — **[confirmed as attribution]** for the scheme, **[candidate]** for any single fabricated example ID. This object carries the `addressing-spine` family: it is the historical antecedent of the project's own digit.role.mode.register address discipline.

**door** — Luhmann's essay (zettelkasten.de) for the design rationale; Schmidt (2018) and niklas-luhmann-archiv.de for the verified structure.
