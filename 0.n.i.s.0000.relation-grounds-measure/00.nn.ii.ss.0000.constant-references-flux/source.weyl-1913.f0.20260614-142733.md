Weyl, Hermann. *Die Idee der Riemannschen Fläche.* Leipzig: B. G. Teubner, 1913.

Role — codification: widely credited with the first modern definition of a two-dimensional manifold (Riemann surface) via an atlas of coordinate neighbourhoods with compatible transition maps, anticipating the general manifold definition later set on a Euclidean footing by [[source.whitney-1936]].

Note — distinct from H. Weyl's 1916 equidistribution paper (see source.weyl-1916, a different work in a different field). Same-author trap noted.
