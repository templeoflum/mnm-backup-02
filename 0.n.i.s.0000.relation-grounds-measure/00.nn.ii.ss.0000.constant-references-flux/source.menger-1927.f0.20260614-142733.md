Karl Menger, "Zur allgemeinen Kurventheorie," *Fundamenta Mathematicae* **10** (1927), pp. 96–115.

Role — origin of Menger's theorem: minimum separating set equals maximum number of disjoint paths.

Note — the result emerged in the context of curve theory / topology; it is the combinatorial seed later generalized to the max-flow min-cut theorem and LP duality.
