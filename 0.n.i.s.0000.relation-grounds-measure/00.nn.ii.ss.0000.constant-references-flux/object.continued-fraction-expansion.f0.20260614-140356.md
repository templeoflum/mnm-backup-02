**statement (plain)** — any real number can be written as an integer plus one-over-(an integer plus one-over-(an integer plus …)). Run the [[Euclidean algorithm]] on the number: the successive integer parts are the "partial quotients" a₀, a₁, a₂, …. For a rational number this terminates; for an irrational it runs forever, and the expansion is unique.

**statement (formal)** — the *simple* (regular) continued fraction of x ∈ ℝ is
x = a₀ + 1/(a₁ + 1/(a₂ + 1/(a₃ + …))), written [a₀; a₁, a₂, a₃, …],
generated by the [[Gauss map]]: set x₀ = x, aₙ = ⌊xₙ⌋, and xₙ₊₁ = 1/(xₙ − aₙ) whenever xₙ ≠ aₙ. Here a₀ ∈ ℤ and aₙ ∈ ℤ₊ (aₙ ≥ 1) for n ≥ 1.
- **finiteness:** x ∈ ℚ ⟺ the expansion is finite.
- **existence & uniqueness:** every irrational has a unique infinite simple continued fraction; every rational has exactly two finite expansions, [a₀; …, aₙ] with aₙ ≥ 2 and [a₀; …, aₙ−1, 1], so uniqueness holds under the convention aₙ ≥ 2 for the last term. **[confirmed]**

**construction** — the partial quotients are exactly the quotients produced by applying the [[Euclidean algorithm]] to the pair (numerator, denominator) in the rational case; this is why the theory is as old as Euclid's *Elements* (anthyphairesis). [[source.hardy-wright-1938]] **[confirmed]**

**lineage** — the algorithm is ancient (Euclid; Bombelli 1572/1579 and Cataldi 1613 for square roots; Wallis coined "continued fraction" and Brouncker gave the first infinite one for 4/π, 1655–59). The first *systematic theory* is Euler's "De fractionibus continuis dissertatio," written 1737, published 1744 (*Comm. Acad. Sci. Petropol.* 9). [[source.euler-1737-cf]] **[confirmed]**
