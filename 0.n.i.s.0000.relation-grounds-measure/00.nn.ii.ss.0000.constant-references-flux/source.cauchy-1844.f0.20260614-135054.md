Full citation — A.-L. Cauchy, note(s) in *Comptes Rendus de l'Académie des Sciences*, Paris, 1844, giving the derivative bounds ("Cauchy estimates") from which a bounded entire function is constant — the result later named Liouville's theorem.

Role — first proof of what is now called Liouville's theorem, arising in the context of Liouville's announcement on doubly-periodic functions; the priority source for the theorem.

Access — historical text; *Comptes Rendus* 1844 (public domain, Gallica/BnF). Attribution reported in Wikipedia ("Liouville's theorem (complex analysis)") and AoPS Wiki. **[confirmed as attribution]**
