**statement (plain)** — appraisal is deciding what to keep. Not every record can or should be preserved forever, so the archivist judges which records have lasting value worth the cost of keeping them, and which can be destroyed or kept only for a set period.

**statement** — appraisal is "the process of identifying materials offered to an archives that have sufficient value to be accessioned," and, in records management, "the process of determining the length of time records should be retained, based on legal requirements and on their current and potential usefulness" ([[source.saa-dictionary]]). It can operate at any level (collection, creator, series, file, item) and weighs provenance, content, authenticity, condition, preservation cost, and intrinsic value. It is distinct from monetary (market-value) appraisal. **[confirmed]**

**basis** — Schellenberg's value framework underpins modern appraisal: records hold **primary value** (usefulness for the purpose for which they were created, to the originating creator) and **secondary value** (usefulness for other purposes, to later users). Secondary value splits into **evidential value** (evidence of the creator's organization and functions) and **informational value** (information on the persons, events, and things the creator dealt with). Appraisal identifies records of enduring secondary value for permanent preservation. **[confirmed]**

**lineage** — Jenkinson ([[source.jenkinson-1922]]) held that the creator/administrator, not the archivist, should select records, to protect impartiality. Schellenberg ([[source.schellenberg-1956]], *Modern Archives*, 1956) reversed this for the modern mass-records archive, giving the archivist an active appraisal role and supplying the primary/secondary and evidential/informational value scheme that still anchors practice. Later theory (macro-appraisal, functional appraisal) builds on and contests this base. **[confirmed]**
