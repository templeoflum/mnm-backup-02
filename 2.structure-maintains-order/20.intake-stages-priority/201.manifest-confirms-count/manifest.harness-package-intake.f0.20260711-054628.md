## intake decision (operator's word, 20260711)

**TAKEN IN as the SPEC WE CONVERGE TO** — but with a standing qualifier:

- **UNPROVEN + EXTERNAL.** It was designed *outside* this running system, so it
  "could only be reasoned through so much from outside — it's probably off a bit."
  We do **not** adopt it verbatim, and its RFC-2119 "MUST" language is held as
  *guidance to adapt*, not law-on-arrival. [[coherence-not-truth]],
  [[hold-positions-provisionally]].
- **The SHAPE is right; the SURFACE must become ours.** We converge toward it,
  then adapt every mechanism to how we ACTUALLY work — proven by running it here,
  not by the spec's authority. Divergences from the spec are findings, not
  failures (the package's own doctrine: "regressions are findings, not redesigns").
- **Convergence path (operator's approach, 20260711):** start by building **small
  mock modules in the mock dispatch**, opened via a **chat→browser link** that
  must work **smooth**, and they **update live** so all seats can look at + work
  on them in real time — **live-update is STANDARD.** Start from the "minimum
  living loop" the package names (two parties, one watched .md, envelope + ledger
  + pulse) — which is already ~half-built in our dispatch.
