# zine-hub

shelf · seeds · submission — the SF02 public hub. A visitor is dealt six seeds on two
shelves (word above, image below), cracks them open, takes one — a conscious agreement
that tags their submission — and sends their piece, signed or unsigned. Intake lands in
the SF02 tree named and sorted at the door.

Developed in-lattice as one unit; only the static output deploys (GitHub Pages, own
repo). Frame in `docs/`. Event: 2026-07-24.
