Watch ζ loop the origin — each loop is a zero.

Control engineers test stability with the Nyquist criterion: trace the input around a contour, plot the output, and count how many times it encircles the origin. That counting rule is the argument principle. So walk s around a box in the critical strip, plot ζ(s) on the right — every time the curve wraps the origin, there's a zero inside the box.

Encirclements of the origin = zeros enclosed by the box.

Why it works. As s walks the box once, ζ's phase must return to where it started — but it can wind around the origin some whole number of times on the way. Each full wind is exactly one zero of ζ caught inside (the box holds no pole, so poles don't subtract). It's the same machine as the field instrument's contour count, wearing its control-theory name. Raise the box top past the next zero's height and watch the loop-count tick up by one.
