## HUD
- **what:** ONE standard for serving the operator anything needing his **word / sign / eye** — the paper, its floor targets, the serve, the handshake.
- **why:** three serve-misses in one morning, all from re-deriving the form instead of reading it. The standard makes the form mechanical; no seat re-derives it again.
- **shape:** three ask-classes → one copyable shell (template at 200) + two pre-created floor targets + one board token.

## §1 — the ask-classes (pick by what you need from him)
- **WORD** — a quick call: board memo, needs-line FIRST naming what + stakes; end `· needs: word` → yup/hold/specify taps sprout.
- **SIGN** — a decision on an artifact: serve a PAPER (§2–§3, this standard). End the serve post `· needs: signature` → the sign tap sprouts.
- **EYE** — a built thing to look at: view-link + feedback-paper, never a bare link; the paper's top IS the view link.

## §2 — the paper (frozen mechanics, lifted from the verified shell — copy, never rebuild)
- copy `template.paperwork-serve` (200); set the FOUR constants: KEY · ADDR · RESPFILE · HEARDPATH.
- **zero-network** (no font CDNs — system stacks) · house tokens · dials over prose · draft auto-saves every keystroke (localStorage) · save → `/write`.
- **fold-save:** save reads the floor response, prepends `## fold @ stamp`, keeps ALL prior content — lossless, newest first; his re-signs never erase.
- **heard on the floor:** a FILE (`heard by:` / `at:` / `ready:`) the paper polls green; multi-seat stamps APPEND below the first; the record is the floor, never browser storage.
- **pre-create + COMMIT both targets before serving** — `/write` writes existing files only; an uncreated target fails his sign "not found".

## §3 — the serve (the sequence, every time, in order)
1. **eye the render first** — screenshot/DOM-probe the paper before it reaches him.
2. board post: needs-line first + **`open:<repo-path> label`** token (path starts `/`, ends `.html` or `.md` — the ONLY thing that sprouts the chat button; the desk/dial is defunct as delivery) + `· needs: signature` tail.
3. his sign FOLDS into the response file — watch that file, not the chat.
4. write + commit your **heard** (by/at/ready) — his open paper flips green; the handshake completes on the record.
5. commit the signed response — the handshake is trail, both stamps in the log.
