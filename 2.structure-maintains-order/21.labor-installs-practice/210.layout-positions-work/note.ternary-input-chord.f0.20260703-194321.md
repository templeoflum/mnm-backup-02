# note — ternary input chord — an unconsidered reading of the ternary

address: 210 (observed in the dispatch build) · clerk, 20260703
FLAG this observation belongs to the grammar/keystone track: keep | rework = keep

The dispatch compose-aim shortcut landed as: key **1** → the 1-seat, key **2**
→ the 2-seat, and **1+2 pressed together** → the **0**-seat. The operator
named it: "another ternary view we haven't really considered."

**The observation, plainly:** the digits usually read POSITIONALLY (0/1/2 as
distinct places). The chord reads them by UNION — two keys and their
combination yield three states: {1}, {2}, {1,2}. Three subsets of a two-element
set, mapped to the three digits, with the union stanging for 0. It's a
different generator of "three from two" than the positional one — closer to a
sum/composition reading than a place reading.

**Why it's worth a note, not a claim:** it fell out of an input-ergonomics
choice, not from the grammar work; whether it's a genuine facet of the ternary
system or just a convenient keymap is exactly the kind of thing the grammar
track settles by use, not by declaration. Filed here so it isn't lost; handed
toward the keystone/grammar work (track 12) for whoever picks that season up.
Not built on, not settled — an observation set down where it can be found.
