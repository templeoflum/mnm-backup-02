# note — mail conventions — what one floor already does (dispatch S2, slice 2.2)

Names the standing practice; invents nothing. Absorbs frame.comms.f1's
chunk-3 stub by reference.

- **memo** — words and pointers on the board (`memo.board` at 222), aimed by
  @mention. Never cargo. Doors: the lattice memos panel · `board.py`
  (post/read/mentions) · POST `/memo`. All land through one lock.
- **freight** — files, moved by commit. Pathspec at both doors, witnessed
  into the books. A document crosses seats by BEING on the one floor; there
  is no attachment, only an address.
- **mail** — a memo that points at freight: address + filename + what's
  wanted (the dive-brief pattern, 20260703). The pointer is the envelope;
  the floor carries the weight.
- **the wake reads the sill** — a seat's wake surfaces board @mentions newer
  than its last baton, so mail is unmissable without polling.
- **board fold rule** — the board is an accumulator: it folds (fN → fN+1,
  clerk's hand, pointer row in the new fold) when it grows long (~200 rows)
  or on a discussed format change, never mid-thread. `op_board` reads the
  newest fold as the live board.
