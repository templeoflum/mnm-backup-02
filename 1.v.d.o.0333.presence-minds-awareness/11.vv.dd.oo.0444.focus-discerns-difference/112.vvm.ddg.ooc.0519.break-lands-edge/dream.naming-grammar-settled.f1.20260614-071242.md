## THE CORE — agreed + accurate (what survived)

**The organizing principle (working spine, well-supported, still float — not "law"):**
A name carries a few **relations**; the system is healthy exactly when the map *relation → carrier* is a **bijection** — every relation carried once, every carrier holding one relation. Collisions (one carrier, many relations) and redundancies (one relation, many carriers) are the only two failure modes. **A grammar is the rule-set that arises to the degree the bijection fails** — so the goal is to maximize the bijection and need almost no grammar. (Independently confirmed by `dream.bijection`: integer base tiles exactly = no legality rules; overlap = cover>1 = a grammar appears.)

**The bones (the relations) and their settled carriers:**

| relation | carrier | state |
|---|---|---|
| **PLACE** | the address / cell | **settled** — already exact & bijective; the exemplar the rest aims at |
| **KIND** | `is` (type), **read off the cells** (wear-pattern, not schema) | held |
| **SUBJECT** | `does` (the thread it concerns) | held |
| **VERSION** | the fold `fN` — the **identity key** | held |
| **MOMENT** | the timestamp — **provenance only, never identity** | held |
| **STAGE** | = PLACE (a growth-kind's stage *is* its address) | dissolved into PLACE |
| **WHO** | — *uncarried* (git-author is degenerate; lives in prose) | open candidate-bone |
| **MEMBERSHIP** | — *uncertain* (the `tsr`/kit question) | decision Q4 |

**The marks — a binding-ladder, one mark per rung:** `/` location  >  `.` slot boundary  >  `-` word-spacing **(one job only)**. Evolution is **not** a mark — it lives in the fold (re-version) or the SUBJECT-thread (new work). Kill `-cycleN`-style suffixes.

**Mobility (the freight/paperwork split):** **freight = moving-`is`** (a growth-kind's KIND advances through cells as it ripens — this *is* STAGE=PLACE); **paperwork = fixed-`is`** (records that witness, don't ripen — log/edge/count/audit/baton). Same 3-slot grammar for both; only is-mobility differs.

**Accumulator-behavior falls out of KIND** (manifest = live, log = append, schedule = refold) — it is *not* a separate mark; `goes` stays simple.

**The razor (the cutting tool, reusable):** *drop any carrier another carrier already determines.* Demonstrated by the operator's S3 sketch (removed the ratio numbers because the address position determines them; `server.py` computes the ratio from digits). Mechanical pass for every slot: "derivable from another carrier? → drop it."
