# compass · log — tsr
**f0 · the present tense: position fixes and declared headings. append-only — a log that rewrites is not a story. THIS LAYER TAKES NO MARKS — the first entry births f1.**

entry form:
`## YYYYMMDD-HHMMSS · [gait] · [clutch N open / fix / miss M / close / hold / audit]`

**an open** declares the bets — written before the act, from the source's OWN words (registry over filename, each item by its own entry, the neighbor's mechanism never a prior), bands not points, the source of every wobble named, the expected exactness bet at what the builder can reach.

**a fix** records what the bench said, against the bet — baseline READ before any sweep (never assumed), active states read where controls matter, at least one route independent of the artifact (analytic, hand-computed, or cross-instrument), arithmetic of any declared receipt recomputed.

**a miss** is carved raw where it happened: where did the wrongness live — the act, the checking, the pencil, or the assumption before the pencil? which prior substituted for which read? clause earned, one sentence. a false alarm is carved the same as a miss — the alarm's anatomy is the lesson.

**a close** runs the checklist: observe · reflect · update map · register specimens · sign · merge. signs by work, never by name.

**a hold** is the receipt of an operator word, whole.
