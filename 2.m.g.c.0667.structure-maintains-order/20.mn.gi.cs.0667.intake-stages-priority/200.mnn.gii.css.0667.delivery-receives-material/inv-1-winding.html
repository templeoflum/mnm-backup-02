The winding number — a count that no deformation can move.

Walk a closed loop around some zeros and count how many times ζ wraps the origin. That integer is a topological invariant: bend the loop into any shape you like — ellipse, star, squiggle — and as long as it still encloses the same zeros, the count doesn't flinch. The only way to change it is to drag the boundary across a zero.

What kind of invariant this is. The winding number survives the largest group of transformations there is — any continuous, invertible deformation of the picture whatsoever (a homeomorphism). That's what "topological" means: it doesn't see distance, angle, or shape, only what's inside what. The price of that robustness is that it tells you almost nothing — just a count. It cannot distinguish two configurations of five zeros from each other. Compare its sibling, the cross-ratio, which survives a far smaller group but in exchange remembers the actual arrangement.
