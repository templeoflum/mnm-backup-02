The cross-ratio — one number that remembers the arrangement.

Four points carry a single number, the cross-ratio, that's unchanged by any Möbius transformation — translate, scale, rotate, even invert (which bends the line into a circle). Here the four points are four zeros on the critical line. Push them through Möbius maps and the number is frozen. Push them through anything else — squaring, or the unfolding we've used all along — and it moves.

What kind of invariant this is. The cross-ratio survives only the Möbius group — small, rigid, just the projective symmetries. The reward for that fragility is memory: it encodes the four points' actual arrangement, so it distinguishes configurations a count never could. But it is not robust the way the winding number is — the very reparametrization we lean on elsewhere, the unfolding, is not Möbius, and it shifts the value. So this number is a coordinate-free fingerprint of spacing within the projective group, and only there.
